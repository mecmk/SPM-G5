## Conventions

- **Primary keys** are UUIDs generated by the database, except reference tables keyed by a
  stable `code` and the infrastructure table `schema_migrations`.
- **Status / kind columns** are `text` with a named `CHECK` constraint; the allowed values
  are listed under each table. Add or rename a value with a migration that replaces the constraint.
- **`created_at` / `updated_at`** are `timestamptz`; `updated_at` is maintained by a trigger.
- **Periods** are half-open: `starts_at` inclusive, `ends_at` exclusive, so back-to-back
  bookings that touch at a boundary do not conflict (story 14.1 AC3).
- **Stories** listed against a table are backlog IDs from the SPM Product Backlog.

### user_sessions

**Stories:** 1.1

Server-side login sessions. The browser holds an opaque random token in an HttpOnly cookie; only its SHA-256 hash is stored here, so a database leak cannot be replayed. Logout sets revoked_at (story 1.1 AC5).

| Column | Type | Null | Default | Key | Description |
| --- | --- | --- | --- | --- | --- |
| `id` | `uuid` | no | `gen_random_uuid()` | PK | - |

| `token_hash` | `text` | no | - | - | SHA-256 hex digest of the session token held by the browser. |
| `created_at` | `timestamp with time zone` | no | `now()` | - | Login time. |
| `expires_at` | `timestamp with time zone` | no | - | - | Hard expiry; the session is invalid after this instant even if not revoked. |
| `revoked_at` | `timestamp with time zone` | yes | - | - | Set on logout. NULL while the session is live. |
| `user_agent` | `text` | yes | - | - | Browser user-agent string at login (troubleshooting aid). |

Rules and indexes:

- unique `user_sessions_token_hash_key`: `UNIQUE (token_hash)`
- index `ix_user_sessions_user_id`: `btree (user_id)`
