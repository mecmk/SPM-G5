# Frontend

React + Vite + TypeScript app for ConnectSphere. See the [root README](../README.md) for full
setup and workflow docs — this file is just a quick reference for when you're already `cd`'d in
here.

## Quick reference

```bash
npm install       # install dependencies
npm run dev       # run the dev server (http://localhost:5173)
npm run build     # type-check and production build
npm run lint      # lint with oxlint
```

Copy `.env.sample` to `.env` and adjust `VITE_API_BASE_URL` if the backend isn't running on the
default port.
